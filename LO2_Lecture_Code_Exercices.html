double calculerTVA(double prixHT) {

double calculerPrixTTC(double prixHT) {

Lecture 2 — Comparer les paradigmes dans un code M2

Voici deux versions du même programme : un distributeur qui calcule un prix avec remise. Compare-les.

Version procédurale

double calculerTotal(double prix, int quantite) {
    double total = prix * quantite;
    if (quantite >= 20) {
        total = total * 0.93;
    } else if (quantite >= 11) {
        total = total * 0.96;
    } else if (quantite >= 5) {
        total = total * 0.975;
    }
    return total;
}

afficher(calculerTotal(10, 15));

Version orientée-objet

public class Commande {
    private double prixUnitaire;
    private int quantite;

    public Commande(double prixUnitaire, int quantite) {
        this.prixUnitaire = prixUnitaire;
        this.quantite = quantite;
    }

    public double getTotalBrut() {
        return prixUnitaire * quantite;
    }

    public double getTauxRemise() {
        if (quantite >= 20) return 0.07;
        if (quantite >= 11) return 0.04;
        if (quantite >= 5)  return 0.025;
        return 0;
    }

    public double getTotalNet() {
        return getTotalBrut() * (1 - getTauxRemise());
    }
}

Lecture 3 — Évaluer de façon critique D2

Voici un code complet qui utilise les trois paradigmes. Ton rôle : l'évaluer de façon critique et proposer des améliorations.

public class GestionClub {

    private ArrayList<String> membres = new ArrayList<>();

    public void afficherMenu() {
        System.out.println("1. Ajouter un membre");
        System.out.println("2. Afficher les membres");
    }

    public void ajouterMembre(String nom) {
        if (nom != null && !nom.isEmpty()) {
            if (nom.length() < 50) {
                if (!membres.contains(nom)) {
                    membres.add(nom);
                    System.out.println("Ajouté : " + nom);
                } else {
                    System.out.println("Déjà présent");
                }
            } else {
                System.out.println("Nom trop long");
            }
        } else {
            System.out.println("Nom invalide");
        }
    }

    public void afficherMembres() {
        for (int i = 0; i < membres.size(); i++) {
            System.out.println(i + ". " + membres.get(i));
        }
    }
}

// Dans la fenêtre principale :

Exercice 2 — Comparer deux codes

Voici deux façons de calculer la cotisation d'un membre en fonction de son âge (moins de 18 : 30 €, moins de 60 : 60 €, sinon 40 €).

// Version A — procédurale
double cotisation(int age) {
    if (age < 18) return 30;
    if (age < 60) return 60;
    return 40;
}

// Version B — orientée-objet
public class Membre {
    private int age;
    public Membre(int age) { this.age = age; }
    public double cotisation() {
        if (age < 18) return 30;
        if (age < 60) return 60;
        return 40;
    }
}

Exercice 4 — Évaluer de façon critique (D2)

Voici un code volontairement imparfait. Ton rôle est de l'évaluer sur les 4 critères vus en cours, puis de proposer une version corrigée.

public class App {
    public static String[] data = new String[100];    // variable publique
    public static int count = 0;

    public static void ajouter() {
        String nom = javax.swing.JOptionPane.showInputDialog("Nom ?");
        if (nom != null && nom.length() > 0) {
            if (count < 100) {
                data[count] = nom;
                count = count + 1;
                System.out.println("Ajouté: " + nom);
            } else {
                System.out.println("Plein");
            }
        } else {
            System.out.println("Vide");
        }
    }

    public static void main(String[] args) {
        while (true) {
            String choix = javax.swing.JOptionPane.showInputDialog("1=ajouter, 2=quitter");
            if ("1".equals(choix)) ajouter();
            if ("2".equals(choix)) break;
        }
    }
}
