Rappel — la notion de variable

Une variable est une boîte ayant un nom, qui permet de stocker une valeur pouvant changer au cours du programme. Elle doit être déclarée avec un type avant d'être utilisée.

double total_ht, total_ttc; int quantite;

total_ht et total_ttc sont de type double (nombres décimaux). quantite est de type int (nombre entier).

Les opérateurs arithmétiques

SigneOpérationExempleRésultat
+Sommeresultat = 3 + 5;8
-Différenceresultat = 7 - 4;3
*Produitresultat = 2 * 5;10
/Quotientresultat = 11 / 2;5,5

L'affectation

InstructionCommentaire
nombre1 = 3;La variable nombre1 contient la valeur 3.
nombre1 = 3 * 2;La variable nombre1 contient le résultat de la multiplication, donc 6.
nombre1 = nombre2 - 6;La variable nombre1 contient le résultat de la différence entre nombre2 et 6.
