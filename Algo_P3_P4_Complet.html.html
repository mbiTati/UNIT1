Partie 3 — Type String et structure switch

Objectifs

  • Type de donnée : String (chaîne de caractères).
  • Structure de contrôle : l'alternative switch.
  • Comparaison de chaînes avec compareTo().
  • Principe DRY (Don't Repeat Yourself) — chasse à la redondance.

Problème

La structure if … else trouve sa limite quand le nombre de conditions devient trop grand. Pour pallier à cette limite, on peut utiliser la structure de contrôle alternative switch, dont voici un exemple :

program Switch {
    int choix;
    afficher("Choisir une des options suivantes : 1 ou 2 ou 3 ou 4");
    saisir(choix);
    switch (choix) {
        case 1:
            afficher ("Vous avez choisi l'option 1");
            break;
        case 2:
            afficher ("Vous avez choisi l'option 2");
            break;
        case 3:
            afficher ("Vous avez choisi l'option 3");
            break;
        case 4:
            afficher ("Vous avez choisi l'option 4");
            break;
        default :
            afficher ("Vous n'avez choisi aucune des options proposées.");
            break;
    }
}

Analyse

Cette structure permet une gestion plus claire de choix (situations) multiples. Selon (traduction de switch) la valeur qui aura été saisie dans la variable choix, la ou les actions associées via la clause case seront exécutées. Ainsi dans cet exemple si l'utilisateur saisit la valeur 2, c'est l'affichage suivant qui sera envoyé :

Vous avez choisi l'option 2

Chaque cas envisagé devra se terminer par la clause break qui arrête le traitement et fait sortir de la structure switch.

La clause default permet de gérer tous les autres cas qui n'ont pas été prévus. Ainsi si l'utilisateur saisit la valeur 8, c'est le texte suivant qui va s'afficher :

Vous n'avez choisi aucune des options proposées.

Les variables scalaires

Une des limites de la structure switch, c'est qu'elle ne peut gérer que des variables de type scalaire. Les variables de type scalaire sont des variables qui peuvent s'incrémenter : en gros chaque valeur du domaine de définition a un suivant unique et un précédent unique.

C'est typiquement le cas des entiers (int) : le suivant de 1 c'est 2 et son précédent c'est 0, le précédent de 2 c'est 1 et son suivant 3, etc.

Mais ce n'est pas le cas avec les nombres décimaux (double) : quel est le seul et unique suivant de 10.25 ? 10.26 ou 10.251 ou 11 ? Ambigu.

Il y a un autre type qui est scalaire : le type char. En effet le suivant de 'A' c'est 'B', et le suivant de 'B' c'est 'C'. Cela est dû au fait que derrière le type char il y a une valeur entière qui varie de 0 à 255. Par exemple la lettre 'A' a pour valeur numérique 65, la lettre 'B' vaut 66, etc.

switch avec char

On peut donc réécrire le programme comme suit :

program Switch {
    char choix;
    afficher("Choisir une des options suivantes : A ou B ou C ou D");
    saisir(choix);
    switch (choix) {
        case 'A':
            afficher ("Vous avez choisi l'option A");
            break;
        case 'B':
            afficher ("Vous avez choisi l'option B");
            break;
        case 'C':
            afficher ("Vous avez choisi l'option C");
            break;
        case 'D':
            afficher ("Vous avez choisi l'option D");
            break;
        default :
            afficher ("Vous n'avez choisi aucune des options proposées.");
            break;
    }
}

Le type String (chaîne)

Il permet d'affecter à une variable une suite continue de caractères (lettres, signes, …).

  • "123456" est une chaîne car délimitée par des guillemets.
  • "Dupont Jean, 10 rue des fleurs." est une chaîne comprenant tous types de caractères.
Attention : une chaîne peut contenir de zéro à n caractères, ainsi "" est une chaîne vide, mais c'est une chaîne, et "A" est une chaîne réduite à un seul caractère, mais c'est quand même une chaîne. Pour expliquer cela on verra plus tard qu'une chaîne est un tableau de caractères. Retenons pour le moment qu'une chaîne est une suite contiguë de n caractères pouvant être réduite à zéro ou un caractère.

L'affectation d'une chaîne à une variable se fait comme pour les autres types de données :

String machine;
machine = "Bonjour tout le monde";

Attention : il ne faut jamais mélanger les types de données. On a souvent tendance au début à considérer que le type caractère et le type chaîne recouvrent la même réalité. Cela est tout à fait faux : un caractère est codé sur un octet, alors qu'une chaîne (quelle que soit sa taille) est constituée d'une suite contiguë de caractères. De la même manière, on ne peut affecter un réel à un entier : l'un est codé sur 4 octets et l'autre sur 2 octets.

Les instructions suivantes sont erronées :

Instruction erronéePourquoi
char uncar; uncar = "Bonjour";Affectation d'un type chaîne à un type caractère.
char uncar; uncar = "B";Même si la chaîne se réduit à un caractère, les guillemets indiquent un type chaîne.
char uncar; uncar = "";Même si la chaîne se réduit à une chaîne vide, les guillemets indiquent un type chaîne.

Par contre, aussi bizarre que cela puisse paraître, on peut concaténer une chaîne et un caractère pour réaliser une nouvelle chaîne. Exemple :

String machine;
machine = "Bonjour tout le mond" + 'e';
// La variable machine contient "Bonjour tout le monde"

Points importants

  • Il FAUT écrire String avec un S majuscule, alors qu'on écrit int ou double totalement en minuscules. Nous verrons plus tard que le type String est en fait une Classe, alors que int et double sont des types primitifs.
  • Le délimiteur d'un char est l'apostrophe ('), alors que le délimiteur d'une chaîne est le guillemet (").

De la même manière que l'on pouvait comparer deux entiers ou deux caractères (mais pas un caractère et un entier !), on peut parfaitement comparer deux chaînes. On devrait donc pouvoir écrire les lignes suivantes :

String ch1, ch2;
if (ch1 >= ch2) {
    actions
}
Malheureusement, comme il a été fait le choix de coller au plus près du langage Java, et que le type String est une Classe, cette écriture bien pratique n'est pas possible. Il faut à la place utiliser la méthode compareTo().

compareTo()

La méthode compareTo() retourne :

  • 0 si les deux chaînes sont égales
  • -1 si la première est inférieure à la seconde
  • 1 si la première est supérieure à la seconde

Voici un exemple de comparaison de deux chaînes :

Program CompareChaines {
    String ch1, ch2;
    int compare;
    ch1 = "ABCDE";
    ch2 = "ABCDF";
    compare = ch1.compareTo(ch2);
    if (compare < 0) {
        afficher(ch1 + " est < à " + ch2);
    } else {
        if (compare > 0) {
            afficher (ch1 + " est > à " + ch2);
        } else {
            afficher ("Ils sont égaux");
        }
    }
}

Si ch1 contient "ABCDE" et ch2 contient "ABCDF", alors à l'issue de l'instruction ch1.compareTo(ch2) la variable compare aura la valeur -1, et donc l'affichage sera :

ABCDE est < à ABCDF

Tous les langages peuvent comparer deux chaînes : ils le font en comparant le premier caractère de chacune des chaînes (en fait ce sont les codes ASCII qui sont comparés). S'il y a égalité, la comparaison est poursuivie sur le caractère suivant, jusqu'à ce que survienne la première inégalité ou qu'il n'y ait plus rien à comparer. Ainsi on peut affirmer que les séquences suivantes sont exactes :

ComparaisonPourquoi
"ABCDEFG" < "Z"Car 'A' (65) < 'Z' (90) : "Z" vient après dans l'ordre alphabétique.
"A" < "a"Car 'A' (65) < 'a' (97) : majuscules avant minuscules dans la table ASCII.
"bbbbb" > "bbbb"Car la première chaîne est plus longue et commence par les mêmes caractères.
"ABCDEFG" < "Z" ne veut pas dire que la chaîne "Z" est plus grande que la chaîne "ABCDEFG" au sens de la taille, mais au sens de « vient après dans l'ordre alphabétique ».

Optimiser le programme Switch — le principe DRY

Si on analyse avec un peu d'attention le programme Switch, on s'aperçoit qu'à chaque option on répète quasiment la même chose avec une petite variante. En programmation, la redondance (répétition) c'est l'ennemi ! À telle enseigne qu'il y a parmi ce qu'on appelle les bonnes pratiques, une qui s'appelle DRY (Don't Repeat Yourself).

Nous allons améliorer notre programme — et cela nous donnera l'occasion d'utiliser le type String :

program Switch {
    char choix;
    String message;

    afficher("Choisir une des options suivantes : A ou B ou C ou D");
    saisir(choix);
    switch (choix) {
        case 'A':
            message = "Vous avez choisi l'option A";
            break;
        case 'B':
            message = "Vous avez choisi l'option B";
            break;
        case 'C':
            message = "Vous avez choisi l'option C";
            break;
        case 'D':
            message = "Vous avez choisi l'option D";
            break;
        default :
            message = "Vous n'avez choisi aucune des options proposées.";
            break;
    }
    afficher(message);
}

Nous avons évité la répétition de l'appel à la primitive afficher() et nous avons mutualisé cet appel : en effet, quelle que soit l'option choisie, il fallait afficher un message. Évidemment ici l'avantage ne saute pas vraiment aux yeux, mais c'est essentiellement parce qu'il nous manque (entre autres) le concept de cumul. Ce qu'il faut bien garder à l'esprit, c'est qu'il faut quand c'est possible faire la chasse à la redondance.

Partie 4 — La notion de cumul

Objectifs

  • Comprendre et utiliser la notion de cumul.
  • Maîtriser les écritures raccourcies (+=, -=, *=, /=).
  • Distinguer cumul numérique et concaténation de chaînes.

Introduction

La notion de cumul est très souvent utilisée en programmation et notamment en gestion, mais elle est aussi assez difficile à appréhender pour les débutants.

Analyse

Cumuler, c'est ajouter une valeur à une valeur existante. Exemple :

int total;
total = 10;
total = total + 5;

Dans cet exemple on ajoute 5 à la valeur contenue dans la variable total (10) et le résultat de cette somme (15) est remis dans la variable total. Pour que cette opération soit possible, le système doit posséder une zone tampon (sorte de variable propre au système) dans laquelle l'addition du contenu de total et de la valeur est effectuée, puis affectation du contenu de cette zone à la variable total.

Attention : pour qu'un cumul puisse se réaliser, il faut que la variable sur laquelle se fera le cumul ait été initialisée au préalable, soit par une affectation soit par un calcul. Exemples : 
int total;
total = 0;
total = total + 2;
ou 
int total;
total = 2 * 4;
total = total + 2;
Le programme suivant n'est pas correct : 
int total;
total = total + 2;   // ERREUR : total n'a pas été initialisé
En effet, il est impossible de faire la somme du contenu de total avec la valeur 2, puisque total ne contient rien. Attention : 0 (zéro) est une valeur comme une autre, alors que rien n'est pas une valeur. Un tel programme « PLANTERAIT » sur n'importe quel système !

Un cumul n'est pas obligatoirement basé sur une somme. Exemples :

int total;
total = 4;
total = total * 2;

total = 4;
total = total - 2;

total = 4;
total = total / 2;

Évidemment, ce qui est possible avec les entiers l'est tout autant avec les nombres décimaux :

double total;
total = 4.5;
total = total * 2;

Les autres écritures

Un cumul peut s'écrire aussi comme suit :

Écriture in extensoÉcriture raccourcie
total = total + 2;total += 2;
total = total - 2;total -= 2;
total = total * 2;total *= 2;
total = total / 2;total /= 2;

Dans les programmes Java, on rencontrera plus souvent l'écriture raccourcie que l'écriture in extenso.

Le « cumul » de chaînes — concaténation

On ne peut pas vraiment appliquer la notion de cumul aux chaînes (String) ; on parle alors de concaténation, qui veut dire « mettre bout à bout ». Exemple :

String ch1, ch2;
ch1 = "ABCD";
ch2 = "EFG";
ch1 = ch1 + ch2;
// Maintenant le contenu de ch1 est : "ABCDEFG"

Évidemment on peut aussi écrire :

ch1 += ch2;
