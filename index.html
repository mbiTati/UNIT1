01 · Objectif de l'unité

Apprendre à écrire du code qui fonctionne et qui se maintient

Programmer, ce n'est pas seulement taper du code. C'est savoir décomposer un problème, écrire un algorithme, choisir un paradigme adapté, et utiliser un environnement de développement professionnel pour transformer cet algorithme en application exécutable.

Unit 1 te fait passer du statut d'utilisateur à celui de développeur. Tu apprends à lire et écrire du code, à comprendre comment il se transforme en programme exécutable, et à corriger méthodiquement les erreurs.

À la fin de cette unité, tu maîtrises les bases : algorithmes, paradigmes de programmation, utilisation d'un IDE, débogage structuré et respect d'un standard de code.

02 · Learning Outcomes

Quatre étapes, une seule progression

Chaque LO prépare au suivant. On définit d'abord un algorithme (LO1), on choisit un paradigme (LO2), on implémente dans un IDE (LO3), puis on débogue et on applique un standard (LO4).

Déboguer et respecter un coding standard

1

Définir un algorithme et décrire le processus de programmation

Comprendre le quoi avant de coder

Un algorithme précède toujours le code. Il faut comprendre comment un algorithme se transforme en programme : quelles étapes techniques interviennent entre l'écriture et l'exécution.

  • Définir un algorithme (exemple : tri à bulles)
  • Relation entre algorithme et code source
  • Rôle du préprocesseur, compilateur, linker, interpréteur
  • Étapes de l'écriture à l'exécution
2

Expliquer les paradigmes procédural, orienté-objet et événementiel

Choisir un modèle de structuration

Trois paradigmes structurent le code de façon différente. Chacun a ses forces, ses limites et ses cas d'usage. Il faut savoir les reconnaître dans un code existant.

  • Procédural — fonctions, séquence, contrôle
  • Orienté-objet — classes, héritage, encapsulation
  • Événementiel — déclencheurs, callbacks
  • Types de données : constantes, variables, structures
  • Portée des variables, passage de paramètres
3

Implémenter des algorithmes de base dans un IDE

Coder, compiler, exécuter

C'est le cœur technique de l'unité. Tu codes en Java dans un IDE professionnel, tu compiles, tu exécutes, tu vérifies. Tu écris du code logique, lisible et maintenable.

  • Développer des applications simples
  • Code logique et maintenable
  • Considérations de sécurité
  • Compiler, gérer et déployer le code
4

Déterminer le processus de débogage et l'importance du coding standard

Corriger avec méthode

Un bug n'est pas une fatalité. Il se traque méthodiquement avec les outils de l'IDE. Et un code écrit dans un standard partagé est beaucoup plus facile à maintenir, pour soi comme pour l'équipe.

  • Watch lists, breakpoints, tracing
  • Corriger vulnérabilités, défauts et bugs
  • Techniques structurées de résolution
  • Coding standard : bénéfices individuels et collectifs
03 · Critères d'évaluation

Ce qui est attendu pour valider chaque LO

Trois niveaux de réussite : Pass (valider), Merit (approfondir), Distinction (évaluer de façon critique). Chaque critère est explicite et vérifiable.

LO1 — Définir un algorithme et le processus de programmation

P1
Définir un algorithme et décrire le processus de construction d'une application.
P2
Déterminer les étapes depuis l'écriture du code jusqu'à l'exécution.
M1
Analyser le processus d'écriture de code, y compris les défis potentiels rencontrés.
D1
Évaluer l'implémentation d'un algorithme dans un langage adapté et la relation entre l'algorithme écrit et la variante codée.

LO2 — Expliquer les paradigmes de programmation

P3
Discuter des paradigmes procédural, orienté-objet et événementiel ; leurs caractéristiques et leurs relations.
M2
Comparer les paradigmes dans le code source d'une application donnée.
D2
Évaluer de façon critique le code source d'une application qui implémente les trois paradigmes, en termes de structure et de caractéristiques.

LO3 — Implémenter avec un IDE

P4
Écrire un programme qui implémente un algorithme dans un IDE.
M3
Améliorer l'algorithme écrit en utilisant les fonctionnalités de l'IDE pour gérer le processus de développement.
D3
Évaluer l'utilisation d'un IDE pour le développement d'applications par contraste avec l'absence d'IDE.

LO4 — Débogage et coding standard

P5
Expliquer le processus de débogage et les facilités de débogage disponibles dans l'IDE.
P6
Expliquer le standard de code utilisé dans le code produit.
M4
Examiner comment le débogage peut aider à développer des applications plus sécurisées et robustes.
D4
Évaluer le rôle et l'objectif d'un standard de code, et pourquoi il est nécessaire en équipe comme pour l'individu.
