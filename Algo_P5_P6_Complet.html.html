Partie 5 — L'itérative for

Introduction

On sait que l'informatique permet (entre autres) de recommencer plusieurs fois une suite d'actions. Jusqu'à maintenant les actions étaient exécutées une fois et le programme s'arrêtait. La boucle for permet de répéter un bloc d'instructions un nombre de fois connu à l'avance.

Syntaxe et fonctionnement

for (déclaration et initialisation variable; test variable; incrémentation variable) {
    actions;
}

Exemple :

program For {
    int nb;
    for (int cpt = 0; cpt < 4; cpt++) {
        afficher("Saisir un nombre : ");
        saisir(nb);
        afficher("Le carré de " + nb + " est : " + nb * nb);
    }
}
Note : cpt++ est un raccourci, il est l'équivalent de cpt = cpt + 1;.

Cette structure de contrôle a cette caractéristique que l'on doit savoir par avance combien de fois au plus la boucle doit s'exécuter. Elle se déroule de la manière suivante :

  1. Affectation de valeur basse à variable.
  2. Si variable <= valeur haute, exécution de action 1 à actions n.
  3. Incrément (ou décrément) de variable de la valeur n.
  4. Retour à l'étape 2. Sinon sortie du bloc et exécution des instructions suivant le marqueur de fin de bloc }.
Remarque : on parle aussi bien d'itérative que de répétitive.

Déroulement pas à pas

Dans l'exemple ci-dessus, l'utilisateur devra saisir quatre fois un nombre et verra s'afficher quatre fois son carré. Pour bien comprendre le fonctionnement, nous allons décomposer les différentes étapes.

cptnbaffichagecommentaire
0 Lors de la première entrée dans le for, la variable cpt est déclarée et prend la valeur de la borne inférieure (0). Elle est comparée à 4. Comme 0 < 4, on exécute les instructions du bloc.

2 Nouvelle incrémentation. cpt vaut 2. 2 < 4, on continue.

3 Nouvelle incrémentation. cpt vaut 3. 3 < 4, on continue.

4 Nouvelle incrémentation. cpt vaut 4. 4 n'est plus < à 4, on sort de la boucle.
Remarque : on a utilisé cpt pour servir de compteur parce que c'était assez parlant, mais on aurait pu tout aussi bien utiliser nb, i ou x. Les valeurs basses et hautes du for ne sont pas forcément des constantes, mais sont souvent des variables.

Variantes (bornes, pas, décrément)

Bornes variables

program ForV2 {
    int nb;
    bornInf = 3;
    borneSup = 7;
    for(int cpt = bornInf; cpt < borneSup; cpt++) { ... }
}
// Ici, l'utilisateur saisit 4 fois (cpt vaudra 3, 4, 5, 6)

Borne saisie par l'utilisateur

program ForV3 {
    int nb;
    bornInf = 0;
    saisir(borneSup);
    for(int cpt = bornInf; cpt < borneSup; cpt++) { ... }
}
// Le nombre d'itérations dépend de l'utilisateur

Comparateur <= (inférieur ou égal)

program ForV4 {
    int nb;
    for (int cpt = 0; cpt <= 4; cpt++) { ... }
}
// Combien y aura-t-il d'itérations ? (Réponse : 5, de 0 à 4 inclus)

Pas d'incrémentation supérieur à 1

program ForV5 {
    int nb;
    for (int cpt = 0; cpt < 4; cpt = cpt + 2) { ... }
}
// Itérations : cpt = 0, 2 (donc 2 itérations)

Incrémentation négative (décrément)

program ForV6 {
    int nb;
    for (int cpt = 4; cpt > 0; cpt--) { ... }
}
// cpt vaut 4, 3, 2, 1 (quand cpt vaut 0, on sort)
Note : cpt-- est le pendant de cpt++ mais au lieu d'incrémenter, il décrémente (équivalent de cpt = cpt - 1).

Le compteur comme variable de travail

program ForV7 {
    int nb;
    for (int cpt = 4; cpt > 0; cpt--) {
        afficher("Le carré de " + cpt + " est : " + cpt * cpt);
    }
}
⚠️ Attention : sauf cas exceptionnel, il ne faut JAMAIS changer la valeur du compteur à l'intérieur de la boucle.

Les cumuls dans le for

Les cumuls sont souvent utilisés dans des situations répétitives. Exemple :

program Notes {
    int nbNotes;
    double total, note, moyenne;
    total = 0;
    moyenne = 0;
    afficher("Saisir le nombre de notes : ");
    saisir(nbNotes);
    for (int cpt = 1; cpt <= nbNotes; cpt++) {
        afficher("Saisir la note : ");
        saisir(note);
        total = total + note;
        moyenne = total / cpt;
    }
    afficher("La moyenne est de : " + moyenne);
}

Pourquoi initialiser moyenne à 0 ?

En effet, moyenne n'est pas une variable utilisée dans un cumul et l'instruction moyenne = total / cpt; ne nécessite aucunement que moyenne ait une valeur. Alors pourquoi cette initialisation ?

La réponse se trouve à la sortie du bloc for, dans la ligne afficher("La moyenne est de : " + moyenne);.

Le langage considère que les instructions du bloc for pourraient très bien ne jamais être exécutées. En effet, si l'utilisateur saisit 0 quand on lui demande le nombre de notes, le pointeur de programme ne rentre pas dans la boucle. Au moment où le pointeur tentera d'afficher la valeur de moyenne, il plantera car moyenne n'aura jamais été calculée !

Partie 6 — L'itérative while

Introduction

La structure répétitive for obligeait à connaître par avance le nombre d'itérations. Il est cependant des cas où il faut pouvoir répéter un traitement de 0 à n fois. C'est très fréquent dans les applications interactives, c'est-à-dire les applications où l'utilisateur dialogue avec l'application.

Syntaxe et règles

program Clavier {
    char caract;
    Saisir(caract);
    
    while (caract != '£') {
        afficher(caract);
        saisir(caract);
    }
}

Ce programme affiche les caractères saisis tant que l'utilisateur n'a pas tapé le caractère '£'. Si l'utilisateur tape '£' dès la première saisie, la boucle ne s'exécute aucune fois.

Structure correcte : pour fonctionner, cette structure répétitive doit toujours être écrite comme suit : 
action sur condition;

while (condition vérifiée) {
    action 1;
    action n;
    action sur condition;
}

Les deux règles impératives du while :

  1. Le while doit être précédé de l'action (ou des actions) portant sur la condition.
  2. La ou les dernières actions réalisées à l'intérieur du bloc dépendant du while doivent être celle(s) portant sur la condition.
Important : toute écriture qui ne respecte pas ces deux impératifs est ERRONÉE, même si apparemment "ça marche". Une erreur de conception provoquera un jour ou l'autre une erreur d'exécution !

Erreurs classiques

Erreur 1 : Oublier la première saisie

Si on supprimait le premier saisir(caract);, tous les cas de figures sont possibles en fonction de ce qu'il y a en mémoire à l'adresse correspondant à la variable. Si la mémoire contient le code de '£', la boucle ne s'exécutera pas. Si elle contient autre chose, l'utilisateur verra s'afficher un caractère ASCII aléatoire qu'il n'a pas saisi.

Erreur 2 : Inverser les actions dans le while

Si dans le while, on inverse saisir et afficher, le premier caractère tapé ne s'affichera pas et lorsque le caractère '£' sera saisi, il sera affiché (ce qui n'était pas prévu).

Conclusion : le programme n'est pas fiable, le pire étant que les erreurs peuvent passer inaperçues. Cette structure est essentielle du traitement de l'information, il faut donc lui accorder une attention toute particulière.

Le type boolean (booléen)

Le type boolean est un type de données particulier : il ne comporte que deux valeurs true (VRAI) ou false (FAUX). C'est un type que nous avons déjà vu implicitement : lorsqu'on écrit if (nb > 10), le système évalue l'expression entre parenthèses. Si oui, il retourne VRAI, sinon FAUX.

Exemple d'utilisation :

boolean sortie;
sortie = false;

while (sortie == false) {
    afficher("Vous êtes dans la boucle while");
    saisir(sortie);
}
afficher("Vous êtes sorti de la boucle");
Note : on aurait aussi pu écrire while (!sortie). Cela se lit "tant que non sortie" ou "tant que sortie n'est pas égal à true". C'est une écriture très courante.

Parcours de chaînes de caractères

L'exemple ci-dessous affiche successivement toutes les lettres d'une chaîne de caractères :

program Lettres {
    String chaine, lettre;
    int longueur, cpt;
    
    chaine = "ABCDEFGHIJHLM";
    longueur = chaine.length();
    cpt = 0;
    
    while (cpt < longueur) {
        lettre = chaine.substring(cpt, cpt + 1);
        afficher(lettre);
        cpt++;
    }
}

Comprendre length() et substring()

La méthode length() fournit la longueur d'une chaîne. Dans le cas présent, longueur contiendra 13.

Attention à l'indice 0 : dans la plupart des langages (Java, C#), l'indice qui permet de parcourir une chaîne commence à 0. Donc si une chaîne fait 13 caractères, on ne pourra aller que jusqu'au 12ᵉ (on commence au 0ᵉ).

Comprendre substring(cpt, cpt + 1) : la méthode substring(debut, fin) récupère un sous-ensemble à partir de la position debut jusqu'à la position fin - 1.

Donc si on avait écrit chaine.substring(cpt, cpt) avec cpt = 0, on aurait tenté de récupérer de 0 à -1, ce qui aurait provoqué une erreur !

Il faut donc bien écrire substring(cpt, cpt + 1) pour récupérer un seul caractère.

Arrêt anticipé dans une chaîne

Dans l'exemple ci-dessous, on veut s'arrêter de parcourir la chaîne dès que l'on a atteint la lettre F :

program LettresV2 {
    String chaine, lettre;
    int longueur, cpt;
    boolean sortie;
    
    chaine = "ABCDEFGHIJHLM";
    longueur = chaine.length();
    cpt = 0;
    sortie = false;
    
    while ((cpt < longueur) && (!sortie)) {
        lettre = chaine.substring(cpt, cpt + 1);
        if (lettre.compareTo("F") == 0) {
            sortie = true;
        } else {
            afficher(lettre);
            cpt++;
        }
    }
}
Rappel : ch1.compareTo(ch2) donne -1 si ch1 est inférieure à ch2, 0 si elles sont égales, et 1 si ch1 est supérieure.

Que fait ce programme ? Tant que le compteur est inférieur à la longueur ET que le booléen sortie est à false : récupérer une lettre, la comparer à "F". Si c'est F, basculer sortie à true. Sinon, afficher la lettre et incrémenter le compteur.
